Note

note

考えていること、あはひでの取り組み、支援の事例を note に書いています。中小企業診断士を目指す方、診断士として働く方、創業や補助金を考えている方に向けた記事を公開しています。

note を読む

連載「25年勤めた会社を辞めた僕のミッドライフ・クライシス」

48歳で25年勤めた会社を辞め、50歳で会社と店をつくるまでを、全6話で書きました。副題は「48歳、人生の予定表から外れてみた。」です。

  1. 48歳、25年勤めた会社を辞めました。
    会社が嫌だったわけではありません。3年かけて取った資格を長く使わないまま過ごし、それでも辞めることを選んだ話です。
  2. 「俺、このままでいいのかな」――48歳でやってきたミッドライフ・クライシス
    人生の「初めて」が減っていく感覚と、残り時間を意識したときに、かえって動きたくなった理由について。
  3. 48歳で会社の肩書きを失ったら、自分には何が残ったのか。
    名刺から会社名が消えて分かった、会社の信用と自分の信用の違いについて。
  4. 会社員時代の「人脈」は、独立したら本当に仕事になるのか。
    名刺の枚数と人脈は違います。仕事を頼まれる理由を、能力と信用に分けて考えました。
  5. 会社を辞めて初めてわかった。僕は会社がけっこう好きだった。
    独立して失ったのは、給料でも肩書きでもなく、毎日そこにあった何気ないやりとりでした。
  6. 50歳になった。48歳で会社を辞めた自分に、今なら何と言うか。
    2年たって、計画どおりにはなっていません。それでも48歳の自分に伝えたいことを書きました。
