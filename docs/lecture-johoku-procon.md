## 第6部：信用とエコシステム／再現の5ステップ（20分）

**「営業力」という言葉が私は大嫌いです。**
「畠中さんは営業力があるから」と言われると、正直「は？」と思う。
26件のうち、売り込んで取ったものはゼロです。では何で来たのか。

### 信用です。

- 仕事は「取りに行く」ものではなく、**貯まった信用の残高から引き出される**もの
- 増える行為：約束を守る／期限より早く出す／返事が速い／頼まれごとを引き受ける／相手の成果に貢献する／会いに行く
- 減る行為：遅れる／雑にやる／抱えて落とす／顔を出さなくなる
- 第2部の4人も、全員が **依頼元に対する信用残高が圧倒的に高い** 状態だった

**第2部の答えと、私の26件は同じ形をしている**

| | 4人（塚越・梁川・鵜頭・石川さん） | 私の26件 |
|---|---|---|
| ブランディング＝信用 | 実績を積んだ結果「〇〇といえばこの人」 | 過去の縁5・前職・顧問先が「畠中に頼めば大丈夫」 |
| エコシステム | 金融機関・商工会・自治体から仕事が流れ続ける | 登録先8つの入口＋顧問先からの紹介7件 |

→ **規模は違うが、構造は同じ。** 4人が10年かけたことの入口に、私は2年で立っている。皆さんは今日から立てる。

**理論的な裏づけ：山口周『人生の経営戦略』の4つの資本**

- **時間資本 → 人的資本 → 社会資本 → 金融資本** の順に転換されていく
- 時間資本を良い学習・良い仕事に投下すると、知識・経験・スキル（人的資本）になる
- 核心：**金融資本を生むのは、信用・評判・知名度といった「社会資本」であって、知識・能力・コンピテンシーといった「人的資本」ではない**
- 金融資本を追いすぎて人的資本・社会資本の形成をなおざりにすると、「表面的な成功は得たが満足感がない」状態になる

→ **「尖っていないとダメ＝人的資本を磨け」は、半分しか当たっていない。**
　お金を生んでいるのは社会資本のほう。だから新人はまず**信用残高を積む**。尖るのは後からついてくる（成功の定義で④を最後にした理由）。

### そして、いちばん大事なのはエコシステム

信用は材料。**エコシステムは仕組み。** 4人の地位をつくったのも、私の11社中7社を連れてきたのも、こちら。

| | 単発の仕事 | エコシステム |
|---|---|---|
| 仕事の来方 | 探す・応募する | 流れてくる |
| 1件終わったら | ゼロに戻る | 次を連れてくる |
| 増え方 | 足し算 | かけ算 |

**私のエコシステム（実データで図にする）**

```
入口①  支部キャリアDB・公的機関の登録（8つ）
          ↓ 案件が来る
       期待以上でやり切る
          ↓
       アンドドット（公的支援が終わってお誘い）＝公 → 民に転換

入口②  過去の縁（前職・地元・弟・scalar）5件
          ↓ 顧問契約
       期待以上でやり切る
          ↓ 信用が貯まる
       顧問先が紹介を出す ────→ 7社（池田紙工・OTC・春蔵・ミセツク・sova・Caneat・Protribe）
          ↑                              ↓
          └────── その7社もまた紹介元になる ─┘
```

- **scalar 1社が、池田紙工とOTCコーヒーの2社を連れてきた。** これが回っている証拠
- 塚越さんの「金融機関からの紹介の何割かが顧問になる」、梁川さんの「貸し手からの信頼で紹介」と同じ形

**回すために必要なのは3つだけ**

1. **入口を複数持つ**（登録先・過去の縁・逆営業）
2. **1件を期待以上でやり切る**（ここでしか信用は貯まらない）
3. **紹介してくれた人に結果を返す**（返さないと循環は1回で止まる）

### 再現の5ステップ（この講義の持ち帰り）

私が2年でやったことを、誰でも辿れる順番にすると次の5つ。

1. **信用の棚卸し** — すでに持っている縁を全部書き出す（＝A．過去の縁5件）
2. **入口に登録する** — 支部のキャリアデータベース、公的機関の専門家（＝B．登録先8件）
3. **来た仕事を期待以上でやり切る** — 残高を増やす。ここが2〜3年（4人の育ち方と同じ）
4. **紹介が出る状態にする** — エコシステム化（＝D．紹介7件）
5. **やらない仕事を決める** — 残高を減らす仕事を切る（＝第7部）

→ **新人が今日できるのは1と2。3で差がつき、4は勝手に回りだす。**

## 第7部：やらない仕事を決める（8分）

**失敗談**

- 1年目、easy で Web 作成をしたことから **Web の仕事を受けた**
- **期待値が高くて疲弊した**
- 1年後、**Web は基本的に受けないと決めた**

**そこから決めたこと**

- いまは **やらない仕事を決めること** がコンサルとして重要
- 自分の価値を高める仕事だけをする
- やる仕事を決めるのではなく、やらない仕事を決める
- **いつでも仕事を切れる状態にする**
- **一つの顧問先に依存しない**
- 自分の生き方を決める
- 自分にしかできないをつくる
- **トップコンサルを目指さない**
- 自分が幸せになる仕事を選ぶ
- **自分が幸せなら周りも幸せになる**

→ 成功の定義②「自分の人生を自分でコントロールしている実感」は、ここから来る。

## 個人ワーク：自分のエコシステムを設計する（24分・受講生21名）

**ねらい**: 話を聞いて終わりにせず、**私と同じ枠を使って、自分の循環を1本描いて帰ってもらう**。
配布物は A4 両面。表がステップ1、裏がステップ2・3。

### ステップ1：入口マップを埋める（10分）

私の26件と**同じ6つの枠**に、自分の名前で書き込む。

| 枠 | 埋めるもの | 目安 |
|---|---|---|
| A 過去の縁 | 前職の同僚・取引先、顧客、地元、家族、友人。思いつく限り**名前で** | 4分 |
| B 登録できる先 | 支部のキャリアデータベース、中小機構、信用保証協会、公社、商工会議所 | 2分 |
| C お誘いをくれそうな人 | 支部の先輩、同期、研究会 | 1分 |
| D 紹介を生みそうな人 | Aのうち、人を紹介してくれそうな人に◎ | 1分 |
| E 逆営業できる相手 | いま自分に営業してきている人（保険・不動産・システム等） | 1分 |
| F 個人的な縁 | 趣味、子どもの縁、地域 | 1分 |

→ **Aは全員が書ける。** 「まだ何も持っていない」と思っている人が、20人くらい書けてしまう。
　**もう持っている**という発見が、この講義でいちばん効く瞬間。

### ステップ2：循環を1本描く（9分）

Aから **1人だけ**選び、矢印を描く。

```
［誰から］→［どんな仕事］→［期待以上に何をするか］→［誰に紹介してもらえそうか］
```

- 1人ぶんでいい。**1本回れば、あとは同じことの繰り返し**
- 講師の例（scalar → 池田紙工・OTCコーヒー）を横に並べて見せる
- 書けたら **「紹介してくれた人に、どう結果を返すか」** を1行足す（循環が止まらないため）

### ステップ3：今日やる1つを決める（5分・発表含む）

- Bの登録先を **その場でスマホから1つ申し込む**（支部のキャリアデータベース等）
- または、ステップ2で描いた相手に **その場で連絡する**
- **行動を完了させて帰る。** 残り時間で発表3〜4名

## まとめ（5分）

- 私の26件は、全部「信用」から来た。売り込んだ仕事はひとつもない
- 尖っていなくていい。**尖りは結果であって、出発点ではない**
- やらない仕事を決めて、自分が幸せになる仕事を選ぶ
- 締めの一言（案）：「私が3年前にこの席で聞きたかったことを、今日は全部お話ししました。数字も名前も出しました。次は皆さんの番です。」
